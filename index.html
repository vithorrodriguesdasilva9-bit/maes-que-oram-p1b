Configurações

Parâmetros locais da versão atual e preparação para hospedagem.

Armazenamento atual

Os novos cadastros são gravados em localStorage. Isso permite uso imediato sem servidor. Na hospedagem definitiva, essa camada pode ser substituída por Supabase, Firebase ou Google Sheets/API sem alterar a experiência visual.

Deduplicação

Filtros, KPIs de paróquias e diretórios usam chaves normalizadas. O sistema preserva os registros originais, mas evita contar diferenças de maiúsculas, espaços e acentos como entidades diferentes.

Backup

Exporte os registros locais antes de trocar de navegador ou computador. O arquivo JSON pode ser importado novamente pela aba Cadastros.

Pronto para host

O app é um único arquivo HTML autocontido, sem dependências externas. Isso facilita publicação em Netlify, Vercel, GitHub Pages ou integração posterior com um backend.
